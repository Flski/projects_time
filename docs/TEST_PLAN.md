**Тест-план**


**1. Объект тестирования:** 

Веб-приложение с авторизацией пользователей, изменением логина, пароля пользователя, удалением учётной записи, созданием, изменением, удалением проектов и задач, а также с функцией таймера для задачи.

**2. Цели тестирования**:

-Проверка корректной работа слоя работы с базой данных

-Проверка корректной работы логики (валидация данных, обработка http запросов, доступ к чтению и изменению данных)

-Проверка корректного отображения данных и ошибок в интерфейсе веб-приложения

**3. Области тестирования:**

**-3.1. Функциональное тестирование:**

-3.1.1. Тестирование регистрации, авторизации

-3.1.2. Тестирование функций учётной записи: изменение логина, пароля, удаления учётной записи

-3.1.3. Тестирование функций проектов: создание проекта, изменение, удаление, просмотр полных данных проекта

-3.1.4. Тестирование функций задач: создание задачи, изменение, удаление, просмотр полных данных задачи

-3.1.5. Тестирование функций таймера задач: запуск таймера, пауза, завершение

**-3.2. Тестирование интерфейса:**

-3.2.1. Проверка страниц приложения на корректность отображения данных 

-3.2.2. Проверка страниц приложения для операций на информативность (объяснение, какие данные корректны)

-3.2.3. Проверка страниц приложения на лаконичность интерфейса

**3.3. Тестирование устойчивости к ошибкам**

-3.3.1. Тестирование операций веб-приложения с некорректными входными данными и с нарушениями правил операций

-3.3.2. Проверка на вывод ошибок при некорректных входных данных или нарушений правил операций

**3.4. Тестирование производительности**

-3.4.1. Оценка скорости операций добавления и изменения данных

-3.4.2. Оценка скорости операций вывода имеющихся данных

**3.5. Тестирование целостности данных**

-3.5.1. Проверка на создание, изменения, удаления проекта для текущего пользователя

-3.5.2. Проверка на создание, изменения, удаления задачи для текущего проекта
