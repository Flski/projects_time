**2. Описание операций**

**2.1. Регистрация.**

-Назначение: Создание учётной записи.

-Входные данные: логин, 2 одинаковых пароля.

-Результат: создание записи в таблице с пользователями в базе данных.

-Используемые SQL-запросы: "INSERT INTO clients(login, password_hash) VALUES (?, ?)".

-Валидация: Проверка на длину логина больше или равной 4 и больше или равной 8 для пароля, проверка на совпадение введённых паролей.

-Обработка ошибок при: При введении длин логина, пароля, не соответсвующих условиям валидации; при несоответствии первого введенного пароля со вторым; при введении логина, который уже есть в записях таблицы с пользователями в базе данных.
